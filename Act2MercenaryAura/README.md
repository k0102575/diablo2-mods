# 액트 2 용병 오라 활성화

D2RMM 오프라인용 개인 모드입니다. 위세, 기도, 인내, 축복받은 조준, 신성한 빙결의 `skills.txt` AI 설정을 조정해 첫 교전에서 오라가 켜지도록 합니다. 가시(Thorns)는 대상에서 제외합니다.

`Act2MercenaryAura` 폴더를 `D2RMM/mods/`에 넣고 활성화한 뒤 **Install Mods**를 실행합니다.

같은 스킬의 `aitype`를 바꾸는 모드가 있다면 이 모드의 값을 적용하려는 경우 그 모드 뒤에 배치합니다. 피해량이나 범위 등 같은 행의 다른 설정은 읽어 온 값을 보존합니다. `aitype`는 공용 스킬 설정이므로 해당 스킬을 사용하는 다른 AI에도 영향을 줄 수 있습니다.

실제 게임 확인은 아직 진행하지 않았습니다. 장비 오라를 빼고 새 게임과 용병 부활 후 각각 첫 교전에서 기본 오라가 켜지는지 확인합니다. 병용 환경에서 적의 오라와 다른 모드의 스킬 변경도 확인합니다.

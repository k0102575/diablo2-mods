# Larzuk Socket Recipe

제작자: 빵길빵길 · 버전: 1.0.1 · D2RMM 오프라인용

**말 룬 1개 + 최상급 보석 1개 + 소켓 없는 장비 1개**를 호라드림의 함에서 조합하여 라주크 소켓 보상과 같은 소켓 개수를 얻습니다. 최상급 해골을 포함한 보석 7종을 사용할 수 있습니다. 룬과 보석은 소모됩니다.

| 장비 품질 | 소켓 개수 |
|---|---|
| 저품질·일반·고급 | 장비 종류와 아이템 레벨이 허용하는 최대 개수 |
| 매직 | 1~2개 무작위. 허용 최대가 1개라면 1개 |
| 레어·세트·유니크·크래프트 | 1개 |

무형 여부와 관계없이 품질별 규칙을 적용합니다. 이미 소켓이 있는 장비, 장갑·장화·벨트·장신구 등 소켓 불가 장비는 대상이 아닙니다. 퀘스트 보상 사용 여부와 관계없이 모든 난이도에서 반복 사용할 수 있으며 실제 라주크 퀘스트 상태는 변경하지 않습니다.

원본 장비를 유지하는 `useitem` 출력으로 옵션·품질·아이템 레벨·무형 상태를 보존하도록 구현했습니다. 수리·충전·재감정은 수행하지 않습니다. 퀘스트의 소켓 결과를 대체하는 모드이며 NPC 상호작용 전체를 복제하지는 않습니다.

## 설치

1. 게임을 종료하고 오프라인 저장 파일을 백업합니다.
2. 모드 폴더를 `D2RMM/mods/LarzukSocketRecipe/`에 넣습니다.
3. D2RMM에서 활성화하고 **Install Mods**를 실행합니다.
4. 오프라인 게임에서 재료 세 개를 조합합니다.

별도 아이템·이미지·드롭 변경은 없습니다. Probabilistic Rune Downgrade와 독립적으로 설치할 수 있습니다. 소켓 제한을 바꾸는 다른 모드가 있으면 설치된 게임 데이터의 제한을 따릅니다. 룬·보석 중첩 모드 사용 시 우선 재료를 단품으로 꺼내 사용하세요.

## 검증 상태

게임 **3.4 / D2RMM 1.9.2 / 병용 환경**에서 아이템 레벨·품질·장비 분류·매직 소켓·재료 및 조합 거부·원본 보존과 저장 테스트 묶음 1~6번의 정상 동작이 사용자에 의해 보고되었습니다. 소켓 장비를 창고에 둔 채 모드를 제거한 뒤 재접속해도 이상 없음을 확인했습니다.

자동 검사 12개는 테이블 처리·경로를 검사하며 실제 게임 검증과 구분합니다. 세부 결과와 미확인 범위는 [검증 기록](docs/TESTING.ko.md)을 참고하세요.

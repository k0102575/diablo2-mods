# Probabilistic Rune Downgrade — 확률형 룬 분해

제작자 **k0102575 (빵길빵길)** · 버전 **1.0.0** · **악마술사의 군림 오프라인 전용** · D2RMM **1.9+**

엘드부터 조드까지 룬을 네 가지 결과 중 하나로 분해합니다. 룬 1개와 룬 분해 망치 1개를 조합하고, 만들어진 분해 대기 아이템만 다시 조합하세요.

## 사용법과 확률

1. 호라드림의 함에 **룬 1개 + 룬 분해 망치 1개**를 넣고 조합합니다.
2. 다른 재료를 모두 빼고 **분해 대기 아이템만 단독으로 재조합**합니다. 추가 재료는 필요하지 않습니다.
3. 아래 결과 중 하나를 받습니다.

| 결과 | 기본 확률 |
|---|---:|
| 바로 아래 등급 룬 2개 | 50% |
| 바로 아래 등급 룬 1개 | 25% |
| 입력 룬 1개 반환 | 10% |
| 룬 분해 망치 1개 반환 — 꽝 | 15% |

엘드(r02)~조드(r33) **전체 32등급**을 지원하며 엘(r01)은 분해하지 않습니다. 두 개 당첨은 원작 업그레이드 재료 수와 관계없이 **모든 등급에서 2개**입니다. 이스트 전용 옵션은 없습니다. 첫 조합에서 룬과 망치를 소비하며, 룬이 나오는 결과에는 망치를 돌려주지 않습니다. 꽝은 룬을 잃고 망치 1개만 돌려받습니다.

네 확률을 각각 **0~100 정수**로 설정하고 합계를 **정확히 100**으로 맞추세요. 잘못된 설정은 설치를 중단합니다. 기본값은 `50 / 25 / 10 / 15`, 동일 확률은 `25 / 25 / 25 / 25`입니다.

## 두 배포판 중 하나 선택

- **Standard:** 모든 입력 룬에 공통 확률 4개를 적용합니다.
- **Tiered:** 하급·중급·고급의 접이식 그룹에 각각 네 확률을 설정합니다.

| 구간 | 입력 룬 |
|---|---|
| 하급 | 엘드~렘 (r02~r20) |
| 중급 | 풀~굴 (r21~r25) |
| 고급 | 벡스~조드 (r26~r33) |

입력 룬으로 구간을 선택합니다. 기본값은 **세 그룹 모두 50/25/10/15**이며 각 그룹 합계를 100으로 맞춥니다. 고급 룬이 자동으로 어려워지는 것은 아닙니다. 이 경계는 모드가 채택한 기준이며 모든 거래 커뮤니티의 공식 분류를 뜻하지 않습니다.

`-standard-mods-only.zip` 또는 `-tiered-mods-only.zip` 중 하나만 설치하세요. 두 판은 같은 폴더를 사용하고 망치·조합·이미지는 같습니다. 소스 폴더를 직접 설치하면 Tiered입니다. 기존 네 설정은 새 12개 설정으로 자동 이전되지 않으므로 설치 전 직접 확인하세요. 판종·확률 변경 전 대기 아이템을 모두 처리하고 백업하세요.

## 두 번 조합하는 이유

첫 조합에서 게임이 1~100의 추첨값을 대기 아이템에 저장하고, 두 번째 조합에서 저장된 값에 해당하는 결과를 지급합니다. 두 번째에 다시 추첨하지 않습니다. 생성된 큐브 조합법으로 설정 가능한 네 결과를 서로 겹치지 않게 처리하기 위한 방식입니다.

## 룬 분해 망치

액트 1 **기드**에게서 구매하는 **비중첩 1×1** 재료입니다. 보통·악몽·지옥 모두 판매하도록 설정했습니다. 기본 가격은 1골드이며 D2RMM 1.9.0 / 게임 3.3 병용 환경에서 구매·판매 각각 1골드와 상점 재고 동작에 이상이 없었다는 제작자 보고가 있습니다. 다른 아이템이나 NPC의 전역 가격 설정은 변경하지 않습니다.

AI 지원으로 제작한 청록색 망치 아이콘과 HD 두 해상도 sprite를 포함합니다. 기존 퀘스트용 망치는 변경하지 않으며 조합 재료가 아닙니다. 클래식은 기존 망치 아이콘을 참조하며 1×1 영역 표시는 아직 확인하지 않았습니다.

이 버전은 룬+주문서 조합을 생성하지 않으며 타 모드 조합법을 보존합니다. 이전 대기 아이템의 꽝 결과도 주문서에서 망치로 바뀔 수 있으므로 업데이트 전에 모두 처리하고 백업하세요.

### 망치 제작

**매직 마울 / 워 클럽 / 오우거 마울 중 1개 + 돌 룬 1개 + 최상급 해골 1개 + 주얼 1개 → 룬 분해 망치 1개**

네 재료는 모두 소모됩니다. 파란 이름의 매직 무기만 허용하며 다른 품질, 그레이트 마울 계열과 한손 망치는 제외합니다. 에테리얼 매직도 허용하도록 설정했지만 실제 게임 검증은 필요합니다. 주얼은 품질을 제한하지 않습니다. 무작위 크래프트 옵션이 아닌 고정된 전용 망치를 지급합니다.

두 판 공통 **기드에게 망치 판매** 옵션은 기본 켜짐입니다. 끄면 판매 재고 생성을 비활성화하며 제작은 항상 가능합니다. 변경 후 Install Mods를 실행하고 새 게임에서 확인하세요. 기존 망치 삭제나 NPC 판매 차단 기능은 아닙니다. 몬스터 드롭 테이블은 수정하지 않습니다.

게임 검증 결과는 아래 검증 범위를 참고하세요.

대기 룬의 툴팁에 실제 결과 룬 이름·수량과 네 확률을 표시합니다. 설치 시 Standard 공통 설정 또는 Tiered 입력 룬 구간 설정을 사용합니다. 저장된 당첨 결과는 표시하지 않습니다. 마지막 색상 수정은 화면 재확인이 필요합니다.

## 분해 대기 아이콘

바론9님의 **빛나는 룬 아이콘**을 대기 아이템에만 적용합니다. 일반 룬·결과 룬은 현재 설치된 그림을 유지합니다. 엘드~랄은 외형 차이가 작으므로 **“— 분해 대기”** 이름으로 구분하세요. HD의 일반·저해상도 아이콘을 제공하며 클래식 그림은 그대로 유지합니다.

## 설치

1. 게임을 종료하고 오프라인 캐릭터·공유 보관함을 백업합니다.
2. `ProbabilisticRuneDowngrade-1.0.0-<edition>-mods-only.zip`을 D2RMM 실행파일이 있는 폴더에 풉니다. `mods/ProbabilisticRuneDowngrade/mod.json`을 확인하세요. ZIP 이름의 바깥 폴더가 추가되면 안 됩니다. 문서 포함 ZIP도 대안이며 둘 중 하나만 설치합니다.
3. D2RMM 1.9+에서 선택한 판종을 켭니다. Standard는 공통 확률 4개, Tiered는 세 구간별 확률 4개씩을 설정하며 각 확률표 합계는 100이어야 합니다. 기드 판매 옵션도 확인하세요.
4. Relics of Sanctuary 병용 시 우리 모드를 **Relics 뒤**에 배치하고 **Install Mods**를 실행합니다.
5. D2RMM 설정에 맞게 오프라인 게임을 실행하고 시험용 세이브 복사본으로 먼저 확인합니다.

## 저장 및 호환 주의

**확률 변경·모드 제거·순서 변경·스탯 추가 모드 설치·게임 업데이트 전에 대기 아이템을 모두 처리하고 저장을 백업하세요.** 대기 아이템이 남아 있으면 확률 변경 후 저장된 추첨값이 새 확률로 재해석됩니다. 모드 순서와 스탯 추가로 대기 아이템의 저장 호환성이 달라질 수 있습니다. 잘못 생성된 이전 대기 아이템의 자동 복구는 보장하지 않습니다.

룬 겹치기·룬 창고는 다른 모드의 기능이며 이 모드에 포함되어 있지 않습니다. 모든 게임 패치와 모드 조합의 호환성을 보장하지 않습니다.

Relics가 동일한 `item-mythic` 속성을 중복 등록한 경우 후속 동일 행의 내부 코드만 생성 테이블에서 변경합니다. 첫 정의·행 위치·스탯을 보존하며 Relics 소스는 수정하지 않습니다. 내용이 다른 중복은 설치를 중단합니다. 일반적인 중복 속성 자동 복구 기능은 아닙니다.

## 검증 범위

D2RMM **1.9.0 / 게임 3.4**에서 0.3.0 등급별 확률과 0.4.0 망치 제작 관련 테스트 케이스가 모두 통과했다고 제작자가 보고했습니다. 게임 3.3에서도 같은 D2RMM 버전의 병용 환경에서 통과했습니다. 3.4의 정확한 빌드와 단독/병용 여부는 별도 미기록입니다.

1.0.0은 해당 기능과 후속 표시 수정을 포함합니다. 안내문은 금색, 대기 룬의 결과 네 줄은 흰색이며 판매 옵션은 두 판 모두 맨 위에 배치했습니다. **마지막 표시 수정의 실제 화면 재확인은 아직 별도로 기록되지 않았습니다.** 스크린샷 촬영 시 색상·줄바꿈·옵션 위치를 확인하세요.

자동 검사 **215개**는 양쪽 판의 전 32등급·추첨값 1~100, 구간별 확률·경계·0%/100%, 설정 오류, 제작 조합과 툴팁 문자열을 검사합니다. 실제 D2RMM·게임 실행 검사는 아니며, 과거 확률 반복 검사는 [검증 기록](https://github.com/k0102575/diablo2-mods/blob/main/ProbabilisticRuneDowngrade/docs/TESTING.ko.md)에 구분했습니다. 클래식 망치 아이콘의 1×1 표시는 미검증입니다. 모든 패치·모드 조합의 호환성을 보장하지 않습니다.

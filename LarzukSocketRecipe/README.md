# Larzuk Socket Recipe

제작자: 빵길빵길 · 버전: 1.1.0 · D2RMM 오프라인용

**소켓 없는 장비 1개 + 아래 룬 1개 + 최상급 보석 1개**를 호라드림의 함에서 조합합니다. 최상급 해골을 포함한 보석 7종을 사용할 수 있습니다. 룬과 보석은 소모되며 장비는 소켓을 추가한 상태로 반환됩니다.

| 장비 품질·작업 | 필요한 룬 | 소켓 개수 |
|---|---|---|
| 저품질·일반·고급 최대 소켓 | **움(Um)** | 장비 종류와 아이템 레벨이 허용하는 최대 개수 |
| **고급 품질만** 랜덤 소켓 | **풀(Pul)** | 1~6 추첨 후 장비·아이템 레벨의 허용 최대치로 제한 |
| 매직 | **말(Mal)** | 1~2개 무작위. 허용 최대가 1개라면 1개 |
| 레어·세트·유니크·크래프트 | **말(Mal)** | 1개 |

여기서 고급은 아이템 품질 **Superior**입니다. 엘리트 베이스를 뜻하지 않습니다. 일반 버서커 액스는 풀 조합 대상이 아니지만, 고급 버서커 액스는 대상입니다. 무형 여부와 관계없이 위 품질별 규칙을 적용합니다.

## 랜덤 소켓

풀 조합은 `1~허용 최대치` 균등 추첨이 아닌 **순정 큐브 방식**입니다. 1~6을 추첨한 뒤 허용 최대치를 넘으면 그 최대치로 줄입니다.

- 최대 6소켓: 각 결과 약 16.67%. 최대치가 6인 고급 버서커 액스에서 **5소켓도 가능**하지만 확정은 아닙니다.
- 최대 4소켓: 1·2·3개 각각 약 16.67%, 4개는 50%.
- 최대 1소켓: 항상 1개.

기본 장비 데이터의 소켓 제한을 전제로 한 기대 확률이며, 최신 게임의 실제 분포를 통계적으로 검증한 결과는 아닙니다. 베이스와 아이템 레벨에 따라 최대치가 달라집니다.

이미 소켓이 있는 장비, 장갑·장화·벨트·장신구 등 소켓 불가 장비는 대상이 아닙니다. 풀 조합 결과가 마음에 들지 않아도 **같은 장비를 다시 추첨할 수 없습니다.** 헬 룬 + 마을 차원문 주문서는 소켓 내용물만 제거하며 소켓 자체를 없애지 않습니다.

퀘스트 보상 사용 여부와 관계없이 모든 난이도에서 사용할 수 있으며 실제 라주크 퀘스트 상태는 변경하지 않습니다. 원본 장비를 유지하는 `useitem` 출력으로 옵션·품질·아이템 레벨·무형 상태를 보존하도록 구현했습니다. 수리·충전·재감정은 수행하지 않습니다. NPC 상호작용 전체를 복제하는 모드는 아닙니다.

## 설치 및 업데이트

1. 게임을 종료하고 오프라인 저장 파일을 백업합니다.
2. 모드 폴더를 `D2RMM/mods/LarzukSocketRecipe/`에 넣습니다. ZIP은 D2RMM이 있는 폴더에 압축 해제하면 이 경로가 됩니다.
3. D2RMM에서 활성화하고 **Install Mods**로 전체 모드를 다시 설치합니다.
4. 오프라인 게임에서 재료 세 개를 조합합니다.

**1.0.x에서 업데이트하면 저품질·일반·고급 최대 소켓 재료가 말에서 움으로 바뀝니다.** 이전에 소켓을 뚫은 장비는 그대로 사용합니다. 별도 대기 아이템이나 저장 데이터 변환은 없습니다. 파일 교체만으로 기존 설치된 게임 데이터가 바뀌지는 않습니다.

별도 아이템·이미지·드롭 변경은 없습니다. 설정창 없이 재료로 조합을 선택합니다. Probabilistic Rune Downgrade와 독립적으로 설치할 수 있습니다. 소켓 제한을 바꾸는 다른 모드가 있으면 설치된 게임 데이터의 제한을 따릅니다. 룬·보석 중첩 모드 사용 시 재료를 단품으로 꺼내 사용하세요.

## 검증 상태

**1.1.0 실제 게임 테스트는 아직 하지 않았습니다.** 자동 검사 15개로 재료·품질·소켓 범위와 기존 조합식/파일 경로 보존을 확인했습니다. 실제 게임의 소켓 결과와 확률 분포를 실행한 검사는 아닙니다.

이전 1.0.x는 게임 **3.4 / D2RMM 1.9.2 / 병용 환경**에서 사용자 테스트를 통과했습니다. 1.0.1 수정 후 겹치기 전환 정상 및 설치 테이블의 기존 행 보존도 확인됐습니다. 이 기록을 1.1.0 테스트 통과로 간주하지 않습니다. [검증 기록과 1.1.0 테스트 항목](docs/TESTING.ko.md)을 참고하세요.

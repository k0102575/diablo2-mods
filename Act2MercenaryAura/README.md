# 액트 2 용병 오라 활성화

D2RMM 오프라인용 0.2.0 테스트판입니다. 액트 2 용병이 첫 교전에서 위세, 기도, 인내, 축복받은 조준, 신성한 빙결 중 자신의 기본 오라를 선택할 가능성을 높입니다.

`Act2MercenaryAura` 폴더를 `D2RMM/mods/`에 넣고 활성화한 뒤 **Install Mods**를 실행합니다.

0.1.0에서는 `skills.txt`의 `aitype`만 바꿨고, 사용자 테스트에서 오라가 발동하지 않았습니다. 레거시 AI 분석에서 `aitype = 1`은 이미 켜진 오라의 재선택을 막는 조건입니다. 0.2.0은 액트 2 사막 용병(`Act=2`, `Class=338`)의 대상 오라 슬롯 `ChanceN`을 최소 10,000으로 올립니다. 게임의 교전 조건과 기술 선택 추첨은 그대로 적용되므로 첫 교전 발동을 보장하지 않습니다. [레거시 AI의 용병 행동 선택](https://github.com/ThePhrozenKeep/D2MOO/blob/master/source/D2Game/src/AI/AiThink.cpp)

가시와 지원 대상 오라가 여러 개 등록된 용병 행은 가중치 변경 대상에서 제외합니다. 같은 행의 기본 공격 및 Jab 가중치, 오라 레벨, 피해량과 범위는 이어 읽은 값을 유지합니다. `aitype`는 공용 스킬 설정이므로 같은 스킬을 사용하는 다른 AI에도 영향을 줄 수 있습니다. 같은 열을 바꾸는 모드가 있으면 이 모드의 값을 적용하려는 경우 그 뒤에 배치합니다.

0.2.0의 실제 게임 테스트는 미완료입니다. 장비 오라를 빼고 새 게임 및 용병 부활 후 첫 교전에서 각각 기본 오라가 켜지는 시점을 확인합니다. 발동 뒤에도 용병이 계속 공격하는지 확인합니다. 결과에는 용병 오라 이름과 앞에 설치한 용병/스킬 모드가 있다면 함께 기록합니다.

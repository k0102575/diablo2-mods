# Probabilistic Rune Downgrade — 1.1.0-alpha.2

## 망치 중첩 보관

드롭과 중첩을 **1.1.0** 업데이트에 함께 제공합니다. 별도 중첩 모드는 필요하지 않습니다.

1. **단품 망치 1개만 단독 조합 → 중첩형 망치 1개**.
2. 중첩형끼리 드래그해 최대 **256개**까지 합칩니다.
3. **묶음만 단독 조합 → 사용 가능한 단품 망치 1개 + 나머지 묶음**. 마지막 1개는 단품만 나옵니다.

묶음은 보관용입니다. 룬 분해에는 꺼낸 **단품 1개**를 사용하세요. 구매·제작·드롭·꽝 반환은 모두 기존 단품 형태입니다. 기존 망치를 자동 변환하지 않고 대기 룬은 중첩하지 않습니다. 다른 버전으로 되돌리거나 제거하기 전 모든 묶음을 단품으로 풀고 대기 아이템도 처리한 뒤 백업하세요.

olegbl의 룬·보석 중첩 코드 패턴을 MIT 조건으로 응용했으며 원저작권 표시와 전문은 `LICENSES/olegbl-MIT.txt`에 포함합니다. **묶음 수량·가격·게임 내 합치기/분리·저장·다른 모드 병용은 실제 게임 검증 전**입니다.

## 망치 몬스터 드롭 — 1.1.0 알파

**실제 D2RMM·게임 테스트 전인 개발 버전입니다.** 1.0.0 검증 결과를 새 드롭 기능의 검증으로 간주하지 마세요.

- **망치 몬스터 드롭:** 기본 OFF. 끄면 드롭 테이블을 읽거나 수정하지 않습니다.
- **망치 드롭 가중치:** 기본 1, 정수 1~1000. ON일 때 적용하며 퍼센트가 아닙니다.
- 보통·악몽·지옥의 액트별 Good 테이블 15개에 망치 후보를 추가합니다. 해당 경로를 사용하는 드롭에서만 추첨하며 모든 몬스터·퀘스트 드롭에 적용된다는 뜻은 아닙니다.
- **기존 룬·보석·장신구 등의 후보와 확률을 나눕니다.** 기존 후보의 가중치·NoDrop·Picks를 직접 바꾸지는 않지만, 후보 합계가 커져 실제 선택 비중은 달라집니다. 인원수와 병용 모드에도 영향을 받습니다. 가중치를 높일수록 영향이 커집니다.
- 대상 행 누락·중복, 빈 후보 칸 없음, 잘못된 가중치·상한 초과 시 설치를 중단합니다. 다른 모드의 후보를 덮어쓰지 않습니다.
- 기드 판매와 제작은 별도이며 기존 망치와 대기 아이템 코드는 유지합니다. 몬스터 드롭은 독립 추가 지급이 아닙니다.


[English description](docs/NEXUS_DESCRIPTION.en.md)

제작자: **k0102575 (빵길빵길)**. 악마술사의 군림(Reign of the Warlock) 전용 오프라인 D2RMM 모드입니다.

룬 1개 + 룬 분해 망치 1개 → 분해 대기 아이템 → 추가 재료 없이 대기 아이템만 다시 조합하여 결과를 받습니다.

| 결과 | 기본 확률 |
|---|---:|
| 바로 아래 룬 2개 | 50% |
| 바로 아래 룬 1개 | 25% |
| 입력 룬 1개 반환 | 10% |
| 룬 분해 망치 1개 반환 — 꽝 | 15% |

엘드(r02)부터 조드(r33)까지 전체 32등급의 룬을 분해할 수 있습니다. 엘(r01)은 분해하지 않습니다. 두 개 당첨은 원작 업그레이드 재료 수와 무관하게 모든 등급에서 2개이며, 이스트 전용 옵션은 없습니다. 네 결과의 확률을 각각 0에서 100 사이의 정수로 설정할 수 있으며, 합계가 정확히 100이어야 합니다. 첫 조합에서 입력 룬과 망치를 소비하며 성공/유지에는 망치를 돌려주지 않습니다. 꽝이면 입력 룬은 소실되고 망치 1개만 반환됩니다.

## 동일 확률판과 3구간 설정판

**두 판 중 하나만 설치하세요.** 망치·조합 방식·결과 수량·아이콘은 동일하며 확률 설정 방식만 다릅니다.

| 판종 | 설정 |
|---|---|
| Standard — 동일 확률판 | 기존 옵션 4개를 모든 입력 룬에 동일 적용 |
| Tiered — 3구간 설정판 | 하급·중급·고급 각각 옵션 4개, 총 12개 |

| Tiered 구간 | 입력 룬 범위 |
|---|---|
| 하급 / Low | 엘드~렘, r02~r20 |
| 중급 / Mid | 풀~굴, r21~r25 |
| 고급 / High | 벡스~조드, r26~r33 |

**입력 룬**을 기준으로 구간을 선택합니다. 예를 들어 풀을 분해하면 중급 확률, 벡스를 분해하면 고급 확률을 사용합니다. 이 구간은 모드에서 채택한 분류이며 모든 거래 커뮤니티의 공식 기준을 뜻하지 않습니다.

기본값은 세 구간 모두 위 표의 **50/25/10/15**입니다. Tiered에서는 각 구간의 합계를 독립적으로 100으로 맞추세요. 고급 룬의 성공 확률이 자동으로 낮아지는 것은 아니며 원하는 값을 직접 설정합니다. 한 구간이라도 값이 잘못되면 그 구간 이름·오류를 표시하고 설치를 중단합니다.

판종을 바꿀 때 예전 4개 옵션이 새 12개 옵션으로 자동 이전되지는 않습니다. 설치 전에 설정을 직접 확인하세요. **판종·확률 변경 전 대기 아이템을 모두 처리하고 세이브를 백업**해야 합니다. 남아 있는 추첨값은 새 확률표로 재해석될 수 있습니다.

## 왜 두 번 조합하나요?

일반적인 큐브 조합법만으로는 한 번의 조합에서 네 가지 아이템 결과 중 하나를 설정한 확률대로 골라 지급하기 어렵습니다. 이 모드는 타락 모드에서 볼 수 있는 ‘먼저 대기 아이템을 만들고, 다시 조합해 결과를 받는 방식’에서 착안했습니다. 구체적인 착안 출처는 아래 크레딧을 참고하세요. 해당 모드의 내부 구현과 같다는 뜻은 아닙니다.

첫 번째 조합에서 게임이 1부터 100 사이의 추첨값을 대기 아이템에 저장하고, 두 번째 조합에서 그 값에 맞는 결과를 지급합니다. 두 번째에 다시 추첨하는 것은 아니며, 추가 재료도 필요하지 않습니다.

## 룬 분해 망치

액트 1의 **기드**에게서 구매하는 전용 재료입니다. 보통·악몽·지옥 모두 판매하도록 설정했으며 **비중첩, 인벤토리 1×1**입니다. 기본 가격은 1골드입니다. D2RMM 1.9.0 / 게임 3.3 병용 환경에서 전 난이도 판매·구매/판매 1골드·재구매가 정상 동작했다는 제작자 보고가 있습니다.

### 망치 제작과 기드 판매 설정

호라드림의 함에서 다음 네 재료를 조합하면 **룬 분해 망치 1개**를 얻습니다.

**매직 마울 / 워 클럽 / 오우거 마울 중 1개 + 돌 룬 1개 + 최상급 해골 1개 + 주얼 1개**

네 재료는 모두 소모됩니다. 파란 이름의 **매직** 무기만 사용하며, 일반·고급·레어·세트·유니크·크래프트 무기와 그레이트 마울 계열·한손 망치는 대상이 아닙니다. 에테리얼 매직도 허용하는 조합이며 실제 게임 확인은 아직 필요합니다. 주얼은 품질을 제한하지 않으므로 보관할 주얼을 재료로 넣지 마세요. 결과는 무작위 옵션이 붙는 장비가 아닌 고정된 전용 망치입니다.

두 판에 공통으로 **기드에게 망치 판매 / Sell hammers at Gheed** 옵션이 있습니다. 기본값은 켜짐입니다. 끄면 기드의 망치 판매 재고 생성을 비활성화하며 제작 조합은 항상 사용할 수 있습니다. 옵션을 바꾼 뒤 Install Mods를 실행하고 새 게임에서 확인하세요. 판매 끄기는 이미 가진 망치를 삭제하거나 NPC에게 파는 것을 차단하는 기능이 아닙니다. 드롭 옵션을 끈 기본 설정에서는 몬스터 드롭 테이블을 변경하지 않습니다.

기드 판매와 제작 기능의 게임 검증 결과는 아래 검증 범위를 참고하세요.

청록색 망치 아이콘은 AI 지원으로 제작했습니다. 퀘스트용 호라드림 망치는 재료가 아니며 기존 퀘스트 아이템을 변경하지 않습니다. HD의 일반·저해상도 sprite를 포함합니다. 클래식에서는 기존 호라드림 망치 아이콘을 참조하며, 1×1 영역의 표시를 포함해 아직 검증하지 않았습니다.

룬+감별 주문서 조합은 이 버전에서 생성하지 않습니다. 다른 모드의 같은 조합법은 그대로 둡니다. 기존 대기 아이템을 남긴 채 업데이트하면 꽝 결과가 주문서에서 망치로 바뀔 수 있으므로 먼저 처리하고 백업하세요.

분해 대기 룬의 툴팁에는 단독 재조합 안내와 실제 하위 룬 이름·수량, 입력 룬 반환 및 꽝(망치 반환)의 확률을 표시합니다. Standard는 공통 설정, Tiered는 입력 룬 구간의 설치 설정을 사용합니다. 0%도 표시하며 저장된 당첨 결과는 노출하지 않습니다. 설정 변경 후에는 툴팁과 결과 판정 모두 새 설정을 따르므로 기존 대기 아이템을 먼저 처리하세요.

## 분해 대기 아이콘

분해 대기 아이템에는 바론9님의 **빛나는 룬 아이콘**을 사용합니다. 일반 룬과 결과 룬의 아이콘은 변경하지 않습니다. 엘드~랄은 회색 계열이라 외형 차이가 작으며, 이름의 **“— 분해 대기”**로 구분하세요. HD 인벤토리의 일반·저해상도 아이콘을 포함하며 클래식 그래픽은 기존 룬 그림을 유지합니다.

## 설치

소스의 `ProbabilisticRuneDowngrade` 폴더를 D2RMM의 `mods`에 복사하면 **Tiered**를 설치합니다. Standard는 빌드된 Standard ZIP을 사용하세요.

간편 설치 ZIP은 다음 중 **하나**를 선택합니다.

- `ProbabilisticRuneDowngrade-1.1.0-alpha.2-tiered-mods-only.zip`
- `ProbabilisticRuneDowngrade-1.1.0-alpha.2-standard-mods-only.zip`

모드·아이콘·라이선스·크레딧을 포함하며 D2RMM 폴더에 풀면 `mods/ProbabilisticRuneDowngrade/`로 배치됩니다. 두 판은 같은 폴더를 사용하므로 동시에 설치하지 않습니다. `-mods-only`가 없는 ZIP은 문서 포함 대안이며 실행 내용은 해당 판종과 같습니다.

1. 게임을 종료하고 오프라인 캐릭터와 공유 보관함을 백업합니다.
2. 간편 설치 ZIP 또는 문서 포함 ZIP 중 하나를 D2RMM 루트 폴더에 풉니다. `mods/ProbabilisticRuneDowngrade/mod.json`이 있어야 합니다.
3. D2RMM 1.9 이상에서 **Probabilistic Rune Downgrade**를 선택하고 확률을 설정합니다.
4. Relics of Sanctuary와 함께 사용한다면 우리 모드를 그 뒤에 두고 Install Mods를 실행합니다.
5. D2RMM 설정에 맞게 오프라인 게임을 실행합니다. 기존 게임 캐릭터 버전 호환성을 확대해 주장하지 않으며 악마술사의 군림용 데이터 `global/excel`만 생성합니다.

## 검증 범위

D2RMM **1.9.0 / 게임 3.4**에서 0.3.0 등급별 확률과 0.4.0 망치 제작 관련 테스트 케이스가 모두 통과했다고 제작자가 보고했습니다. 게임 3.3에서도 같은 D2RMM 버전의 병용 환경에서 통과했습니다. 3.4의 정확한 빌드와 단독/병용 여부는 별도 미기록입니다.

1.0.0은 해당 기능과 후속 표시 수정을 포함합니다. 안내문은 금색, 대기 룬의 결과 네 줄은 흰색이며 판매 옵션은 두 판 모두 맨 위에 배치했습니다. **마지막 표시 수정의 실제 화면 재확인은 아직 별도로 기록되지 않았습니다.** 스크린샷 촬영 시 색상·줄바꿈·옵션 위치를 확인하세요.

자동 검사 **300개**는 양쪽 판의 전 32등급·추첨값 1~100, 구간별 확률·경계·0%/100%, 설정 오류, 제작 조합과 툴팁 문자열을 검사합니다. 실제 D2RMM·게임 실행 검사는 아니며, 과거 확률 반복 검사는 [검증 기록](docs/TESTING.ko.md)에 구분했습니다. 클래식 망치 아이콘의 1×1 표시는 미검증입니다. 모든 패치·모드 조합의 호환성을 보장하지 않습니다.

## Relics of Sanctuary 호환 및 저장 주의

Relics가 완전히 같은 `item-mythic` 속성을 두 번 등록하면 두 번째 이후 속성의 내부 코드에 별칭을 부여합니다. 첫 Mythic 정의와 모든 행 위치·스탯은 유지하고 Relics 소스는 수정하지 않습니다. 내용이 서로 다르면 설치를 중단합니다. 기타 중복 코드의 자동 복구는 제공하지 않습니다.

**모드 제거·순서 변경·다른 스탯 추가 모드 설치·게임 업데이트 전 대기 아이템을 모두 처리하고 저장을 백업하세요.** 추첨값은 첫 조합에서 고정됩니다. 대기 아이템을 남겨 둔 채 확률만 바꾸면 저장된 값에 새 확률이 적용되어 결과가 재해석됩니다. 스탯 ID는 현재 테이블 끝에 추가되므로 모드 구성이나 순서 변경으로 저장 호환성이 달라질 수 있습니다. 이전에 잘못 생성된 대기 아이템의 자동 복구는 보장하지 않습니다.

테스트하지 않은 모드 조합이나 예상치 못한 상호작용으로 충돌이 발생할 수 있습니다.

## 개발 및 배포물 제작

저장소 루트에서 Node.js 18+로 `node tools/verify.mjs`, Python 3에서 `python3 tools/build.py`를 실행합니다. 합성 fixture로 설치 생성기를 검사하고 ZIP 내부 파일별 SHA-256 및 ZIP 자체의 SHA-256 파일을 생성합니다. 공개 조사 테이블이 준비된 경우에만 해당 원문을 사용하는 별도 검사를 실행합니다. 게임 원본 테이블이나 다른 모드의 실행 코드는 포함하지 않습니다. 출처의 통합 배포 허용에 따라 포함한 아이콘은 [외부 자산 크레딧](CREDITS.md)을 참고하세요.

검증과 ZIP 제작은 위 로컬 도구로 실행합니다. 저장소의 GitHub Actions 워크플로는 제거했습니다.

MIT 라이선스는 이 저장소에서 작성한 코드와 문서에 적용합니다. Diablo II 및 게임 자산의 권리는 각 권리자에게 있습니다.

# 1.1.0-alpha.2 — 드롭 및 중첩 통합 검증

자동 검사 **300개 PASS**. 실제 게임 검증 전인 개발판이다. 기존 1.0.0 또는 아래 alpha.1 기록을 새로운 중첩 기능 검사로 간주하지 않는다.

## 중첩 자동 검사

- 두 판에서 단품/묶음 코드와 HD 표시 연결, 중첩 상한·상점/드롭 제외 필드 확인.
- 1~256 각 수량에서 정확히 단품1 + 나머지 묶음으로 변환, 0개 출력 없음.
- 256개에서 반복 인출 시 256단품·잔여0의 수량 보존 확인. 이것은 엔진 실행이 아닌 생성 조합의 논리 검사다.
- 분해/꽝/제작/드롭 코드가 단품 prh를 유지함을 확인. 보관형 phs는 직접 분해하지 않음.
- quantity 스탯 위치 변경 추적, 누락/중복·새 코드 충돌에서 쓰기 전 중단, MIT 전문 해시 보존 확인.

## 실제 게임 중첩 검사

1. 기존 대기 아이템 처리·백업 후 한 판 설치. 게임/D2RMM 버전·빌드·병용 목록 기록.
2. 기존·기드 구매·제작·몬스터 드롭 단품이 모두 단독 큐브 조합으로 묶음1이 되는지 확인.
3. 묶음끼리 합쳐 수량2/5/256 확인. 상한 초과 합치기에서 합계가 보존되고 한 묶음이256을 넘지 않는지 확인.
4. 묶음1/2/5/256 단독 조합: 단품1과 나머지, 마지막에는 단품만 출력되는지 확인. 여러 회 반복해 합계 보존 확인.
5. 룬+묶음은 조합되지 않고, 꺼낸 단품+룬은 기존 방식대로 소모·네 결과 지급되는지 확인. 꽝은 단품1만 반환.
6. 저장/재접속·바닥 드롭/줍기·창고 이동·매각 시 수량과 가격 확인. 다른 룬/보석 중첩 모드 병용에서 우리 묶음이 외부 분리 조합과 충돌하지 않는지 확인.
7. 기드 판매/드롭 ON/OFF 조합과 두 판 확인. 버전을 되돌리기 전 모든 묶음은 단품으로 풀어야 한다.

자동 검사 **273개 PASS**: 양쪽 판 기존 회귀 검사, 기본/누락 OFF에서 드롭 표 읽기·쓰기 없음, 15개 후보 추가·원본 보존·가중치1/17/1000, 희소 슬롯/외부 후보 보존, 잘못된 옵션, 행·컬럼 누락/중복, 가득 찬 목록, 기존 망치 후보, 잘못된 수치·안전 상한 오류의 쓰기 전 중단을 검사했다.

## 실제 게임 확인 항목

1. 대기 아이템을 모두 처리하고 세이브 백업. 판종·게임/D2RMM 버전·빌드·병용 목록 기록.
2. 드롭 OFF로 설치: 기존 제작/판매/네 결과와 구간별 확률이 정상인지 확인.
3. ON/가중치1 설치: 생성된 15개 Good 행의 망치 후보와 값, 기존 후보 보존 확인.
4. 시험용 설정에서 가중치를 높여 드롭 경로를 사용하는 적을 처치하고 망치 바닥 표시·줍기·분해 재료 사용 확인. 큰 가중치의 시연을 기본 드롭률로 기록하지 않는다.
5. 난이도별 대표 경로, 병용 모드 순서, 기드 판매 OFF에서도 드롭과 제작 가능, 저장·재접속 확인. 모든 적이 Good 경로를 쓰지는 않는다.
6. OFF로 되돌려 재설치·새 게임에서 후보가 빠지고 기존 망치는 유지되는지 확인. 다른 모드가 작성하는 TC 출력 파일 자체는 남을 수 있다.
7. Standard/Tiered 두 판에서 옵션 위치와 동일한 드롭 설정 동작 확인. 두 판 동시 설치 금지.

## 자동 검사와 ZIP 검증

`node tools/verify.mjs`는 Node VM의 모의 D2RMM API로 설치 생성기를 실행한다. `LOCAL_VALIDATION.json`에 소스 해시·날짜·판별 검사 수·한계를 기록한다.

- 두 판에서 전체 32등급과 추첨값 1~100을 검사한다.
- 구간별 다른 확률, 경계, 단일 0%/100%, 합계·형식·값 누락 오류를 검사한다.
- 같은 확률일 때 두 판의 게임 데이터가 일치하는지 비교한다.
- 세 제작 조합의 입력·출력, 재료 코드 누락/중복, 판매 옵션과 구형 설정 기본값을 검사한다.
- 실제 룬 이름·네 확률·결과 줄 색상·문자열 저장 순서를 검사한다.
- 아이템/속성 충돌, Relics 동일 중복 처리, 원래 룬·퀘스트 망치·외부 조합 보존과 자산 해시를 검사한다.
- 잘못된 입력에서 파일/자산 쓰기 전 중단과 조합 행 안전 상한을 검사한다.

`python3 tools/build.py`는 위 보고서의 소스 해시가 현재 파일과 일치하는지 확인하고 두 판 ZIP을 생성한다. 파일 구성·내용·ZIP 무결성과 SHA-256을 확인하며 원본 게임 표나 내부 작업 문서를 포함하지 않는다. 엔진 동작과 실제 화면은 이 검사로 대체할 수 없다.

## 남아 있는 확인 범위

- 마지막 표시 수정의 실제 화면, 영어 화면과 1×1 클래식 망치 렌더링.

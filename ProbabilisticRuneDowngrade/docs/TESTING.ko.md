# 검증 기록 및 추가 확인 방법

## 실제 게임 테스트 환경 및 결과 (0.1.0)

제작자의 악마술사의 군림 오프라인 환경에서 확인했습니다. 단독 테스트는 D2RMM 1.9.2, 기존 모드 병용 테스트는 D2RMM 1.9.0으로 진행했습니다. 병용 환경에는 Relics of Sanctuary, 룬 겹치기, 타락 모드가 포함됩니다. 실제 게임 빌드 및 전체 활성 모드 목록은 기록하지 않았습니다.

아래 결과 순서는 **하위 룬 2개 / 하위 룬 1개 / 입력 룬 유지 / 꽝**입니다.

| 환경 | 설정 확률 | 테스트 내용 | 결과 횟수 |
|---|---|---|---|
| D2RMM 1.9.2, 이 모드만 설치 | 각 결과를 차례로 100% 설정 | 네 결과와 수량 확인 | 모두 정상 |
| D2RMM 1.9.2, 이 모드만 설치 | 기본값 50 / 25 / 10 / 15 | 41회 | 24 / 10 / 2 / 5 |
| D2RMM 1.9.0, 기존 모드들과 병용 | 25 / 25 / 25 / 25 | 정식 배포 전 100회 | 27 / 25 / 23 / 25 |
| D2RMM 1.9.0, 기존 모드들과 병용 | 25 / 25 / 25 / 25 | GitHub 정식 배포본으로 50회 | 9 / 15 / 10 / 16 |

Relics 병용 중 발견된 대기 아이템의 저항 감소 표시 및 재조합 불가 문제는 동일한 Mythic 속성 중복 등록 호환 처리 후 정상 동작을 확인했습니다.

## 0.1.0 한 옵션 0% 실제 게임 추가 검사

보고일: **2026-11-06**. 제작자가 **0.1.0**에서 다음 설정을 각각 **10회**, 총 **40회** 실제 게임에서 조합했고 이상이 없었다고 보고했습니다. 정확한 실행 일시는 별도로 기록하지 않았습니다.

확률 순서는 **하위 룬 2개 / 하위 룬 1개 / 입력 룬 반환 / 꽝(감별 주문서)**입니다.

| 설정 확률 | 0%로 설정한 결과 | 실행 횟수 | 사용자 보고 |
|---|---|---:|---|
| 33 / 33 / 34 / 0 | 꽝 | 10회 | 이상 없음 |
| 33 / 33 / 0 / 34 | 입력 룬 반환 | 10회 | 이상 없음 |
| 33 / 0 / 33 / 34 | 하위 룬 1개 | 10회 | 이상 없음 |
| 0 / 33 / 33 / 34 | 하위 룬 2개 | 10회 | 이상 없음 |

실행 환경은 **D2RMM 1.9.2 / 게임 버전 3.3**입니다. 게임의 정확한 빌드 번호, 단독/병용 여부, 사용 룬 등급 및 결과별 횟수는 아직 확인하지 못했습니다. 기존 테스트의 환경을 이 검사에 임의로 적용하지 않습니다. 따라서 이를 병용 검사 완료나 전 등급 검사 완료로 확대하지 않습니다.

이는 실제 게임의 짧은 기능 검사 결과이며 정확한 확률 분포의 증명이 아닙니다. 자동 검사에 사용한 네 설정과는 33/34 배치가 일부 다르므로 실제 사용한 위 값을 그대로 기록합니다. 0.1.1 대기 아이콘 및 0.2.0-alpha.1 분해 망치 검증 결과로 간주하지 않습니다.

## 정식 버전 변경 및 로컬 검증

0.1.0은 사용자가 제공한 테스트 완료 mod.js를 기준으로 이름·제작자·버전을 정리하고 이스트 전용 옵션을 제거했습니다. 이제 항상 32등급/3,232개 조합을 생성합니다. 이전 설정 파일에 istOnly=true가 남아 있어도 무시합니다.

`node tools/verify.mjs`의 검사 결과는 LOCAL_VALIDATION.json에 있습니다. 합성 fixture의 생성/분포/설정 오류/스탯 보존/중복 Mythic 호환 검사를 수행하며 실제 게임 실행을 대신하지 않습니다. 사용자가 제공한 최종 TSV 4개를 이용한 별도 생성기 검사도 수행했습니다. 미제공 테이블 및 문자열/HD는 합성 자료로 보완했습니다.

## 새 환경에서 짧게 확인하려면

1. 캐릭터·공유 보관함을 백업하고 복사한 시험용 세이브를 사용합니다.
2. 확률을 각각 100%로 설정해 네 결과를 한 번씩 확인합니다. 설정 변경 전 대기 아이템을 모두 처리하고 게임을 종료한 뒤 재설치합니다.
3. 기본 확률에서 대기 아이템 하나를 만들어 저장·종료·재접속한 뒤 단독 재조합합니다.
4. 다른 모드와 병용 시 설치 로그, 입력·출력·수량과 표시 이상 여부를 확인합니다. 대량 반복은 필수가 아닙니다.

모드 제거·순서 변경·게임 업데이트 전 모든 대기 아이템을 처리하세요. 잘못 생성된 이전 대기 아이템의 자동 복구는 보장하지 않습니다.

## 미검증 범위

한 옵션만 0%이고 나머지가 양수인 네 설정(0/34/33/33, 33/0/34/33, 33/33/0/34, 34/33/33/0)은 전체 등급·추첨값 자동 검사를 통과했습니다. 별도로 위에 기록한 0.1.0의 네 설정은 각각 10회 실제 게임에서 이상이 없었다고 보고됐습니다. 해당 검사의 병용 여부는 아직 확인하지 못했습니다. 게임 버전 3.4에서의 동작은 검증하지 않았으며 기존 결과를 3.4 검증 결과로 간주하지 않습니다.

### 추가 확인 절차

백업한 시험용 세이브에서 다음 항목을 참고할 수 있습니다. 위에서 보고된 확인 결과와 별도로 미보고 항목은 실제 확인 후 기록합니다.

1. 기존 대기 아이템을 처리하고 종료한 뒤 0.1.1을 설치한다.
2. 일반 이스트 룬의 그림은 그대로인지 확인하고 룬+낱장 주문서를 조합한다. 대기 아이템만 빛나는 그림인지 확인한다.
3. 대기 아이템을 바닥에 내려놓고 다시 줍는다. 모델·이름·아이콘이 정상인지 확인한다.
4. 대기 아이템을 저장한 뒤 종료·재접속하고 단독 재조합한다. 결과 룬이 기존 룬 그림을 사용하는지 확인한다.
5. 저등급 회색 룬은 이름으로 구분하고, 가능한 경우 낮은 텍스처 설정·클래식 그래픽도 확인한다.

룬 이미지 모드 병용 환경에서도 위 절차를 확인한다. 과거 0.1.0 게임 결과를 새 이미지의 동작 확인으로 간주하지 않는다.

## 0.2.0-alpha.1 전용 망치 연결

자동 검사 58개 PASS. 새 재료 prh 및 종류 prgh, 기드 판매 필드·난이도 업그레이드 방지, 비중첩 1×1, 기존 퀘스트 망치·룬·외부 조합법 보존을 검사했다. 모든 등급·추첨값에서 망치 입력과 꽝의 망치 1개 반환을 확인했다. 주문서 행이 없거나 중첩 상태여도 더 이상 우리 모드의 선행 조건이 아님을 검사한다. 새 코드 충돌·판매 필드 누락·망치 원본 그래픽 누락 시 쓰기 전 중단을 확인한다. 일반/저해상도 망치 sprite 2개의 해시·구조를 검사하며 기드 실판매·1골드 가격을 자동 검사로 검증했다고 주장하지 않는다.

집에서 확인할 순서:

1. 구버전 대기 아이템을 처리하고 종료·세이브 백업 후 이 브랜치의 모드 폴더 전체를 복사한다. D2RMM에서 재설치한다.
2. 보통·악몽·지옥 각각 기드에게 망치가 보이는지 확인한다. 구매와 되팔기의 화면 가격 및 실제 골드 증감이 모두 1인지 기록한다. 구매 후 재구매·상점 재방문도 확인한다.
3. 한 칸 크기·비중첩·툴팁·청록색 그림을 확인한다. 원래 퀘스트 망치가 바뀌지 않았는지도 확인한다.
4. 이스트 룬+망치로 대기 아이템을 만들고, 바닥에 내려놓았다 줍고, 저장·재접속 후 단독 재조합한다.
5. 꽝을 100%로 설정하면 룬이 사라지고 망치 하나만 나오는지 확인한다. 나머지 세 결과 100%도 순서대로 확인한다. 설정 변경 전에 대기 아이템을 처리한다.
6. 기본값 및 한 옵션만 0%인 네 설정을 확인하고 병용 모드의 기존 룬+주문서 조합이 유지되는지 확인한다.
7. 클래식 그래픽에서는 기존 망치 그림을 참조한다. 1×1에 맞는지 미검증이며 HD 결과와 구분해 기록한다.

## 0.2.0 버전 확정 (2026-11-07)

## 0.3.0-alpha.1 — 3구간 설정 및 두 배포판

2026-11-09: 자동 검사 **171개 PASS**. 기존 생성기 검사 각각 58개를 Standard/Tiered 양쪽에 실행하고 55개 추가 시나리오를 검사했다. 세 구간의 확률을 다르게 설정해 전 32등급·각1~100 추첨값에서 결과·수량을 검사하며 렘20/풀21,굴25/벡스26 경계도 포함한다. 각 그룹의 단일0%/100%,오류합계·형식·값누락에서 쓰기전중단을 검사한다. 세 그룹이 같은 확률이면 Standard와 생성되는 전체 테이블·HD매핑·문자열·복사목록이 동일한지 비교했다. 이전 4개 설정이 Tiered를 조용히 덮어쓰거나 누락된 그룹값을 대신하지 않는지도 검사했다.

**실제 D2RMM 옵션 UI 및 게임 검사는 아직 하지 않았다.** 기존0.2.0 결과는 새 구간 기능의 실제 검증이 아니다.

### 실제 검사 권장 순서

1. 기존 대기 아이템 처리·백업 후 판종 하나만 설치한다. 설치한 모드의 표시가 Tiered/Standard 중 무엇인지 확인한다.
2. Tiered는 세 그룹과 각4개 옵션이 보이는지 확인한다. 기본값은 모두50/25/10/15다. 기존 사용자확률은 자동 이전되지 않으므로 직접 확인한다.
3. 하급100/0/0/0,중급0/100/0/0,고급0/0/100/0으로 설정한다. 렘20은풀21과,굴25는벡스26과 다른 결과를 내는지 확인한다. 각 입력 룬에 해당하는 하위 룬 또는 반환 룬이 정확한지 확인한다.
4. 각 그룹 꽝을100%로 설정해 룬이 소실되고 망치1개만 반환되는지 확인한다. 변경 전 모든 대기 아이템을 처리한다.
5. 그룹별 합계를99나101로 만들면 해당그룹을 설명하며 설치가 중단되는지 확인하고 정상값으로 복구·재설치한다.
6. 대기 아이템을 저장·재접속한 뒤 추가 재료 없이 재조합한다. 기드 판매·가격·새 망치·대기 아이콘이0.2.0과 같은지도 확인한다.
7. 모든 대기 아이템 처리후Standard로 교체한다. 네 옵션만 보이고 모든 등급에 같은 확률이 적용되는지 확인한다. 판종을 섞거나 동시에 설치하지 않는다.
8. 판종·D2RMM·게임 버전·정확한빌드·병용모드목록 및 설정을 기록한다.
